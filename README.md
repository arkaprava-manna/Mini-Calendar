# Mini Calendar 📅

A simple, elegant mini calendar built using vanilla JavaScript, HTML, and CSS. It dynamically fetches the current date from the user's system and displays the day, date, month, and year in a clean, modern UI.

**[🟢 View Live Demo](https://arkaprava-manna.github.io/Mini-Calendar/)**

## ✨ Features
* **Dynamic Date Rendering:** Automatically updates to show the current day, month, and year using the JavaScript `Date()` object.
* **Modern UI:** Styled with a beautiful gradient background and a two-tone card layout.
* **Custom Typography:** Integrated with the **Poppins** font from Google Fonts for a sleek look.
* **Responsive Design:** Centered using CSS Flexbox, ensuring it looks great on any screen size.

## 🛠️ Tech Stack
* **HTML5** - Structure and layout
* **CSS3** - Styling, Flexbox, and gradients
* **JavaScript (Vanilla)** - DOM manipulation and date logic

## 🚀 Getting Started

Since this is a vanilla web project with no dependencies, running it locally is incredibly easy.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arkaprava-manna/Mini-Calendar.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd Mini-Calendar
   ```
3. **Open the project:**
   Simply double-click `index.html` to open it in your default web browser, or use an extension like **Live Server** in VS Code.
